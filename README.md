# عداد رحلات GPS

تطبيق أندرويد Flutter لقياس الرحلات:
- مشي
- دراجة
- سيارة
- سرعة حالية
- مسافة
- أعلى سرعة
- متوسط سرعة
- مدة الرحلة
- حفظ آخر 20 رحلة
- إحصاءات
- تشغيل بالخلفية عبر Foreground Service وإشعار دائم

## طريقة البناء بدون برامج على اللابتوب

1. أنشئ مستودع GitHub جديد باسم:
   gps-trip-meter

2. ارفع محتويات هذا المجلد إلى المستودع:
   - pubspec.yaml
   - lib/main.dart
   - .github/workflows/build-apk.yml

3. افتح تبويب Actions في GitHub.

4. شغّل:
   Build Android APK

5. بعد انتهاء البناء، حمّل:
   gps-trip-meter-apk

## ملاحظة مهمة

عند التشغيل على أندرويد:
- اسمح للموقع.
- اسمح بالإشعارات.
- للتشغيل بالخلفية، لا تغلق التطبيق بالقوة من مدير التطبيقات.
