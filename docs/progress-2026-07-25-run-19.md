# تقدم التطوير — منع تداخل تحديثات GPS الخلفية

## ما تمت مراجعته

- آخر بناء ناجح وملف APK المحدث.
- `GpsTaskHandler` ودورة `onRepeatEvent`.
- مهلة `Geolocator.getCurrentPosition` في العزل الخلفي.
- تخزين الرحلة النشطة داخل `SharedPreferences`.
- مسار GitHub Actions والتحليل والاختبارات والبناء.

## المشكلة

تعمل دورة الخدمة الخلفية كل 10 ثوانٍ، بينما يسمح طلب الموقع بالانتظار حتى 12 ثانية. على جهاز بطيء أو بإشارة GPS ضعيفة قد تبدأ دورة جديدة قبل انتهاء السابقة، فتحدث قراءتان وكتابتا تخزين متزامنتان للحالة نفسها.

## التغيير

أضيف حارس داخل `GpsTaskHandler` يسمح بتحديث خلفي واحد فقط في اللحظة نفسها:

- يتجاهل الدورة الجديدة مؤقتًا عندما يكون تحديث سابق ما زال جاريًا.
- يعيد فتح الحارس داخل `finally` حتى عند فشل طلب الموقع.
- يستخدم المسار نفسه عند بداية الخدمة وفي الدورات الدورية.
- لا يغير معدل العشر ثواني ولا حساب السرعة أو المسافة.

## الاختبارات

أضيف `test/background_update_guard_contract_test.dart` للتحقق من وجود الحارس، ومن إعادة تحريره داخل `finally`، ومن استخدام المسار الآمن في الدورة الدورية.

تم تحديث GitHub Actions لدمج التغيير، ثم تنفيذ التنسيق والتحليل وجميع الاختبارات قبل بناء APK.
