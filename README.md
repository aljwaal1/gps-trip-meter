# عداد رحلات GPS - Practical V3

نسخة عملية ومتوازنة: إشعار هادئ، حفظ مستمر، واستعادة الرحلة إذا أوقفها النظام.

## ما تم تعديله
- إشعار خلفية هادئ وغير مزعج.
- حفظ الرحلة تلقائيًا كل 5 ثوانٍ.
- استعادة الرحلة إذا أوقفها النظام.
- تحسين رسالة استعادة الرحلة.
- إزالة Watchdog العنيف من نسخة V2.
- تقليل ضغط الخلفية حتى لا يصبح التطبيق مزعجًا أو ثقيلًا.
- الحفاظ على نفس تصميم التطبيق الأساسي.

## ملاحظات
- لا تضغط Clear All أثناء الرحلة.
- اجعل التطبيق Not optimized من إعدادات البطارية.
- على بعض الأجهزة القديمة قد يوقف النظام التطبيق رغم كل الإعدادات، لذلك ميزة الاستعادة مهمة.
