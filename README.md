# عداد رحلات GPS - V4 (أداء + خلفية + تصميم احترافي)

نسخة محسّنة بالكامل من الناحية الهندسية: نفس الفكرة والوظائف، لكن الكود أصبح أسرع، أكثر استقرارًا في الخلفية، ومنظّم بشكل احترافي.

## أهم التحسينات

### الأداء
- فصل الشاشة الحيّة (السرعة، المؤقت، الإحصاءات) عن سجل الرحلات، بحيث لا يُعاد بناء كل الشاشة (بما فيها 20 رحلة سابقة + رسم بياني) كل ثانية — فقط الجزء الحي يتحدث.
- استبدال `GridView` المتداخل داخل `ScrollView` (مشكلة أداء معروفة في فلاتر) بشبكة بسيطة بدون تكلفة Sliver إضافية.
- تقليل القراءة من التخزين (`shared_preferences`) من مرة كل ثانية إلى التزامن فقط عند عودة التطبيق من الخلفية، مع تحديد الحد الأدنى بين عمليات الحفظ على القرص (throttling) أثناء التتبع النشط.
- تقليل عدد نقاط GPS التي تُطلب حسب نوع الرحلة (مشي/دراجة/سيارة) لتقليل الحسابات غير الضرورية بدون التأثير على الدقة.
- تنظيم الكود في ملفات منفصلة (theme / models / services / widgets / screens) بدل ملف واحد ضخم، مع إعادة استخدام الديكورات والأنماط بدل إنشائها من جديد في كل بناء.

### الخلفية
- تم استبدال آلية صلاحية البطارية القديمة (قناة Native غير مفعّلة فعليًا) بحزمة `permission_handler` الموثوقة، بحيث يعمل زر "السماح بالتشغيل في الخلفية" فعليًا.
- طلب صلاحية "السماح طوال الوقت" (Allow all the time) تلقائيًا بعد منح صلاحية الموقع الأساسية، لتحسين فرص استمرار التتبع في الخلفية.
- حفظ فوري وإجباري للرحلة عند انتقال التطبيق إلى الخلفية (paused)، بالإضافة إلى الحفظ الدوري كل 5 ثوانٍ.
- بقاء آلية استعادة الرحلة كما هي: إذا أوقف النظام التطبيق فجأة، يمكنك عند فتحه استكمال الرحلة أو حفظها أو حذفها.

### التصميم
- توحيد كل الألوان في ملف واحد (`AppColors`) بدل تكرارها كقيم متفرقة، لضمان اتساق الألوان وسهولة تعديلها مستقبلًا.
- شعار دائري متدرج اللون في الأعلى، وتنظيم أوضح للبطاقات والظلال.
- نفس هوية التطبيق البصرية الأساسية (الأزرق الهادئ) لكن بتفاصيل أنظف.

## ملاحظات
- لا تضغط Clear All أثناء الرحلة.
- اجعل التطبيق Not optimized من إعدادات البطارية (الزر متاح داخل التطبيق الآن ويعمل مباشرة).
- على بعض الأجهزة القديمة قد يوقف النظام التطبيق رغم كل الإعدادات، لذلك ميزة الاستعادة ما زالت مهمة.

## البنية الجديدة للكود
```
lib/
  main.dart                  نقطة الدخول
  theme/app_colors.dart      كل الألوان
  theme/app_theme.dart       الثيم + ديكورات معاد استخدامها
  models/trip_mode.dart      أنواع الرحلات (مشي/دراجة/سيارة)
  models/trip_record.dart    نموذج الرحلة المحفوظة
  services/geo_utils.dart    دوال GPS/تنسيق مشتركة
  services/trip_session.dart منطق التتبع، الحفظ، الخلفية كاملاً
  widgets/common_widgets.dart عناصر واجهة قابلة لإعادة الاستخدام
  screens/home_screen.dart   الشاشة الرئيسية
```
